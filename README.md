# Данные опроса «Отношение горожан к искусственному интеллекту — Санкт-Петербург, 2025»

Этот репозиторий содержит результаты опроса жителей Санкт-Петербурга об их отношении к технологиям искусственного интеллекта.  
Сбор данных проведён в 2025 году через онлайн-сервис **Анкетолог**.

## Структура данных
**Файл:** `Survey_2025_AI_spb_2.xlsx`  
**Формат:** Microsoft Excel (.xlsx)

Каждая строка соответствует одному респонденту.  
Анкета включала следующие разделы:
- демографические характеристики участников;  
- уровень осведомлённости об ИИ;  
- отношение к использованию ИИ в разных сферах (медицина, образование, транспорт, творчество и др.);  
- восприятие рисков и преимуществ внедрения ИИ.
